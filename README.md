# EnConvert Homebrew Tap

Homebrew tap for the [EnConvert CLI](https://github.com/enconvert/cli).

```sh
brew install enconvert/tap/enconvert
```

On Homebrew 6+, the first `brew tap enconvert/tap` (or the install one-liner above)
asks you to trust this third-party tap — confirm to proceed.

The cask in `Casks/` is generated automatically by the release pipeline in
[enconvert/cli](https://github.com/enconvert/cli); do not edit it by hand.
